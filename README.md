# 最強チームメーカー

ランダムに現れる選手を「取る」か「見送る」かだけで、最強の9人を作るブラウザゲーム。

## 遊び方（コンセプト）

- 選手はポジション関係なく **完全ランダム** で1人ずつ登場する
- できる操作は「取る」「見送る」の2つだけ
- 「見送る」は **5回まで**
- 9人集めたら、打順と守備位置を自分で決める
- 適性外のポジションに置くと評価が下がる

捕手が来ない。投手ばかり来る。ショートがいない。
**「9人集めること自体が難しい」** ことがこのゲームの面白さです。

## 技術構成

- HTML / CSS / JavaScript のみ（フレームワーク・ビルド不要）
- 選手データは `data/players.json` に分離
- 結果画像の生成は `html2canvas`
- 公開は GitHub Pages を想定

## フォルダ構成

```
baseball-team/
├── index.html        ... ゲーム本体（全画面を切り替えて使う）
├── css/
│   └── style.css     ... 見た目
├── js/
│   └── main.js       ... 画面切り替え・起動処理
├── data/             ... 選手データ（STEP 2 で作成）
└── images/           ... 画像（基本は使わず自動生成）
```

## ローカルでの動かし方

ブラウザで直接 `index.html` を開いてもトップ画面は表示されますが、
STEP 2 以降は選手データ（JSON）を読み込むため、**簡易サーバーが必要**です。
最初からサーバー経由で確認することをおすすめします。

```bash
# このフォルダの中で実行
python3 -m http.server 8000
```

実行後、ブラウザで http://localhost:8000 を開いてください。
止めるときは `Ctrl + C` です。

## 注意

登場する選手名・球団名はすべて **架空** のものです。
実在の選手写真・選手名・球団名は、著作権／肖像権／商標の対象となるため使用していません。
